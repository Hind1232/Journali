# Journali

Journali is a simple journaling app for iPhone. It lets users write, organize, and manage their personal journal entries in a clean dark interface.

## Main Features
- Splash screen and an empty state that guides new users
- Add a new journal with a title and text
- Edit an existing journal
- Bookmark journals
- Search journals by title or text
- Sort journals by bookmark or entry date
- Swipe to delete, with a confirmation alert
- Alert before discarding unsaved changes

## Technologies Used
- Swift and SwiftUI
- MVVM architecture
- Xcode
